# Deep Equity Research

一个面向上市公司基本面研究的 Agent Skill，默认使用中文输出。

它支持：

- 对指定上市公司进行深度研究。
- 每日筛选一家值得研究的上市公司。
- 分析商业模式、ROE/ROIC、杜邦驱动、客户粘性和定价权。
- 评估管理层、经济护城河、市场预期与安全边际。
- 类比其他公司的经济特征与护城河机制，说明相似点、关键差异和适用边界。
- 输出可复算的三情景估值、敏感性分析、证伪红线与空头观点。

## 报告阅读顺序

1. 公司如何赚钱：产品、客户、商业模式、上下游与竞争格局。
2. 竞争优势与护城河：客户粘性、定价权、价值创造与捕获。
3. 经济特征与护城河类比：用机制相似的公司帮助理解标的，同时说明关键差异和类比边界。
4. 财务质量与资本效率：盈利、现金流、资本回报、扩张成本，以及停止扩张后维持经营的股东现金检验。
5. 管理层与资本配置：治理、激励、并购、分红与回购。
6. 未来增长与关键变量：增长来源、经营预测及预测边界。
7. 市场预期、估值与安全边际：方法适用性、三情景模型、价值桥接、不扩张估值倍数的回报检验及折扣依据。
8. 核心投资命题与反方论证：核心赌注、成立条件与最强反证。
9. 结论与跟踪清单：区分新买、持有与退出判断，列证伪红线、下一验证时间及有历史记录时的假设变更。

“核心灵魂十问”作为内部研究检查，答案融入对应章节，不再重复成章。估值须提供输入、公式、中间计算及每股价值结果；证据不足时按实际可支持的范围交付。

## 安装

本项目不需要发布到 npm。以下命令会临时运行 npm 上的 `skills` CLI，再从 GitHub 克隆本仓库并安装其中的 `SKILL.md`。

安装到当前项目：

```bash
npx skills add TangHuaiZhe/deep-equity-research
```

安装到本机的全局 Agent Skills 目录：

```bash
npx skills add TangHuaiZhe/deep-equity-research --global
```

也可以将 `SKILL.md` 手动复制到目标 Agent 的 Skills 目录。仓库必须保持可访问；如果仓库是私有仓库，使用者需要具备相应的 GitHub 访问权限。

## 数据要求

本 Skill 优先通过平安资讯/证券 Skill 获取行情和结构化财务数据，不可用或不覆盖时尝试腾讯自选股，再使用其他专用金融工具。公司、交易所或监管机构的原始披露可以直接提供财务证据；数据冲突以适用期间的原始披露及更正公告为核验依据。网页搜索可定位材料，搜索摘要、媒体转述和模型记忆不得用于拼凑核心数字。

使用平安资讯时，请按其 Skill 说明在本机配置 `PINGAN_SKILL_APIKEY`。平安和腾讯均不可用时，会继续尝试其他可靠来源；是否完成报告取决于证据充分性。缺少行情时可完成商业与财务研究，但不判断当前价格；缺少核心财务或估值输入时暂停相应数值结论，并列出缺口。请勿将 API Key（接口密钥）提交到仓库或粘贴到公开对话中。
